# AstroMeow: NASA Space Apps 2026 submission (EN)

Challenge: **Build a Junior Astronaut Mission Trainer** (#3)

## Project title
AstroMeow: Train Like an Astronaut with Astro the Cat

## High-Level Project Summary
AstroMeow is a free browser game for kids aged 7-12 that teaches how astronauts live and work in space. Kids follow Astro the cat along a mission trail from Earth to the Moon and Mars. They answer short quizzes, play five arcade mini-games (flappy flight, shooter, catching supplies, landing, packing a rocket) and use the points to build and upgrade their own space base on planets. Every choice about energy, oxygen and safety has a visible result, so kids learn resource and safety decisions by playing. It runs on a phone or a laptop, needs no account and collects no personal data.

## Detailed Project Description
- **What it does:** quiz missions, 5 mini-games, a base builder with a shop, skins for Astro, local leaderboard, and a "Facts" tab about NASA, ESA and POLSA missions (including the Polish-led IGNIS mission).
- **How it works:** a single offline-capable HTML file. All lessons and questions live in JSON config files, so teachers can add stages without code.
- **Why it matters:** kids get an instant reward after each lesson, then see their knowledge turn into a growing base. This keeps younger learners engaged.
- **Tools:** HTML, CSS, JavaScript (canvas, Web Audio), Python + SQLite for the visit counter, SVG icons.

## Hackathon Journey
Our team built AstroMeow in two days in Stalowa Wola. We wanted space to feel close to kids: astronauts from NASA and ESA are real people and space is closer than it seems. The hardest part was keeping the game fun while keeping every fact correct. We thank our mentors and the organisers.
